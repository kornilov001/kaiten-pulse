# Kaiten Pulse: план

Приложение живёт в строке меню macOS и в трее Windows, запускается при входе в систему и показывает ближайшие карточки Kaiten.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Формат | Иконка в трее и всплывающая панель 384×600, которая скрывается при потере фокуса. В Dock не показывается (macOS) |
| Стек | Tauri 2 (Rust) + React 19 + TypeScript + Tailwind 4 + TanStack Query |
| UI-skill | `frontend-design` от Anthropic (Apache-2.0), лежит в `../.claude/skills/frontend-design` |
| Токен Kaiten | Хранится в связке ключей ОС (Keychain / Windows Credential Manager). Запросы к API выполняет Rust, токен не попадает в webview |
| Фильтр по умолчанию | «Я ответственный» (`responsible_ids`). Можно переключить на «Я участник», выбрать пространства, показывать очередь и карточки без срока |
| Автозапуск | Включается при первом запуске (LaunchAgent на macOS, реестр Run на Windows). Отключается в настройках |
| Сборка | macOS (universal) и Windows (NSIS и MSI) через GitHub Actions: `.github/workflows/build.yml` |

## Этапы

1. **Каркас и ядро.** Готово: трей, панель, автозапуск, single-instance, Keychain, прокси к API, настройки.
2. **Список и «горизонт сроков».** Готово, проверено скриншотами на демо-данных.
3. **Уведомления и статус в трее.** Написано, на реальной системе не запускалось.
4. **Действия с карточкой.** Готово на демо-данных:
   - отметить готовой (перенос в первую колонку типа «done» на доске);
   - перенести в другую колонку;
   - перенести срок: причина обязательна и записывается комментарием в карточку;
   - добавить комментарий;
   - отмечать пункты чек-листа.
5. **Горячая клавиша.** Написано. Сочетание проверяется до сохранения:
   - занятые системой отклоняются (встроенный список; на macOS ещё и то, что включено в «Системные настройки → Клавиатура → Сочетания клавиш»);
   - занятые другим приложением отклоняются на Windows (система сама отказывает в регистрации). macOS разрешает нескольким приложениям одно сочетание, поэтому там такой конфликт не определить.
6. **Первая сборка на GitHub и проверка на реальном Kaiten** (kan-pro.kaiten.ru). Следующий шаг.
   - Сверить: ссылку на карточку, `checklists` в ответе `GET /cards/{id}`, `GET /cards/{id}/comments`, даты без времени.
7. **Установщики.** `.dmg` для macOS и `.exe` для Windows без подписи разработчика.
   - macOS при первом запуске: правый клик → «Открыть» (или «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»).
   - Windows: SmartScreen → «Подробнее» → «Выполнить в любом случае».
8. **Позже.** Значок в Dock, автообновление, подпись кода.

## Что нужно от владельца

- Пустой приватный репозиторий на GitHub и доступ для отправки кода (см. переписку).
- После первой сборки: установить приложение на Mac, ввести `kan-pro.kaiten.ru` и свой API-токен в окне приложения, сообщить, что работает не так.

## Как запустить

```bash
npm install
npm run dev          # UI в браузере на мок-данных: http://localhost:1420
npm run tauri dev    # настоящее приложение (нужен macOS/Windows с рабочим столом)
npm run tauri build  # установщик для текущей ОС
```
